Privacy & notices

PDF Forge does not upload your documents. The web version downloads the app and its PDF engines from its host. The host can process ordinary web request data. File contents are processed locally in your browser or desktop app.

Theme settings, recent filenames and reading positions are stored on this device. Open files stay in memory unless you explicitly pin a local copy to the File shelf. You can remove that copy without changing the original. Browser copies can be removed by clearing site data. Clear recent file details from the File shelf.

The desktop-only Office converter uses an installed LibreOffice executable and a temporary output folder. It does not use a cloud conversion API.
